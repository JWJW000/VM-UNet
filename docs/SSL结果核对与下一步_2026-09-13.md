- **10% 标注训练样本完全一致。** SSL split 与纯监督 manifest 的 189 组图像/掩码文件名集合逐对相等。
- **摘要中的“验证划分不同”不能直接采信。** SSL split 只有 labeled/unlabeled，没有 val；三组每轮验证混淆矩阵总像素均为 52,953,088=808×256×256，GT 前景总像素均为 12,889,591。当前仓库 SSL 代码使用完整 `val/`；纯监督 manifest 也有 808 张，文件名为 0–807。这支持它们很可能使用同一验证目录，但缺少实际运行源码、逐图 SSL 评估清单和数据哈希，尚不能证明逐图完全一致。
- **训练协议没有完全匹配。** SSL 日志 labeled batch=8、unlabeled batch=16；10% SSL 每轮 106 次更新，共 31,800 次。纯监督配置 batch32，189 张每轮 6 次更新，共 1,800 次，使用 corrected 和 T_max300。当前 main 的旧 SSL 入口继承 T_max50 和旧增强，但服务器有未归档修改，不能据此断言实际运行参数。相同 300 epochs 不代表相同更新预算，不能将差异归因于扫描一致性或教师中的单个机制。
- **服务器实际运行代码未完整提交。** 纯监督 environment.json 记录 HEAD=`9f39c74eaeac19d699aed12876a63f581be42620`，同时列出多份 modified/untracked 文件，包括 train_ssl.py、engine.py、models/vmunet/vmamba.py 等。当前 main 的 SSL 入口按验证 loss 选模，本批日志却是每轮按 Dice 选模。因此拉取最新 main 不等于取得实际运行源码，禁止直接覆盖服务器未提交修改。

## 3. 用户更新后的方向判断

用户已明确放弃 MambaLiteUNet。原先建议取回并续跑它的判断撤回，不再将它作为下一任务。

当前真正的进展是建立了可用的 10% 标注监督起点（189 张、Dice 86.9841%），而非证明扫描半监督有效。保留 VM-UNet 骨干，优先研究如何让剩余 1697 张未标注图产生额外收益；这将论文问题转为有限标注下的学习效率。单种子开发验证结果仍不足以支撑稳定性或原创贡献。

建议下一候选：基于少标注监督初始化的标注/未标注区域双向混合学习，参考 [BCP，CVPR 2023](https://openaccess.thecvf.com/content/CVPR2023/html/Bai_Bidirectional_Copy-Paste_for_Semi-Supervised_Medical_Image_Segmentation_CVPR_2023_paper.html) 与[官方实现](https://github.com/DeepMed-Lab-ECNU/BCP)。其核心是双向混合有标注与未标注图像，对应混合 GT 与教师伪标签，分区域监督；官方程序有预训练与自训练两阶段。论文/官方实验主要在 ACDC、LA、Pancreas，不能据此承诺 ISIC 增益。采用现有 VM-UNet/监督权重属于适配试验，不是原样复现 BCP，也不能将它包装成原创。

理由：已有监督起点可复用，而当前配方以去除扫描方向后的预测一致性为主要无标注约束。后者的一致性并不等于预测正确。区域混合提供一种把有标注监督引入未标注上下文的不同学习机制。该机理值得验证，但现有结果未证明扫描扰动、伪标签噪声或分布差异中的哪一个是退化根因。

建议首轮只做 10% seed42 的两组匹配新阶段：

- 对照：从同一个少标注监督 best 初始化，继续仅用189张标注图训练。
- 候选：同一初始化、标注样本/增强/监督批次预算、相同更新步数及学习率计划，加上基于教师预测的区域混合；停止使用原扫描丢弃和方向一致性。

固定每组更新次数和验证频率，另报额外无标注前向/反向带来的实际 GPU 时间；不要再用不一致的300 epochs冒充同预算。未标注图的GT禁止进入训练、伪标签筛选与选模；验证集也不能用于训练。初始化权重曾按验证集选出，后续仍属于开发实验。

新阶段首先必须超过 86.9841% 和匹配继续训练对照；可将约 +1 个 Dice 百分点（约87.9841%）作为值得扩大研究的目标，不作为效果预测。正向后再做多种子和与完整 BCP、UniMatch 等强方法的对照。直接拼接现成方法不是论文创新，后续独立贡献需要新的具体问题和消融证据。

[UniMatch](https://github.com/LiheYoung/UniMatch) 可作为弱强增强路线的相关对照，有官方医学分割实现；本轮不同时上多个骨干或候选。先归档服务器未提交源码、固定协议并完成适配检查，再谈启动训练。当前只有新路线建议，没有新模型实现、GPU运行或预期涨点保证。
