### 新入口的固定设置

- 模型配置与当前 ISIC 基线一致：depths=[2,2,2,2]，decoder=[2,2,2,1]，drop_path=0.2，单类输出。
- 默认 BCE + per-image soft Dice；全部训练样本使用人工标注；没有教师、伪标签、扫描扰动。
- AdamW，lr=0.001，weight_decay=0.01，batch_size=32，300 epochs，256×256。
- 默认 cosine T_max=epochs，避免旧 T_max=50 在 300 轮中反复下降/上升；这是一项协议变化，**尚不能据此解释旧异常**。可用 `--t-max 50` 做专门对照。
- `--preprocessing corrected`：每次增强重新采样旋转角，掩码最近邻缩放；图像仍用与旧实现代数等价的逐图 min-max 到 [0,255]，对常量图防除零。
- `--preprocessing legacy`：保留初始化单角度旋转、掩码双线性缩放；仅用于受控诊断，不保证复现旧训练随机轨迹。
- 新入口显式设图像缩放 antialias=False，与旧 torchvision 0.14 张量 resize 默认行为对齐。跨环境比较应核对 torchvision 版本。
- 默认 workers=0，保存 Python/NumPy/Torch/CUDA/DataLoader RNG；恢复必须用同一 output 与相同参数。
- 每轮记录实际训练 lr、train loss、validation loss、pooled Dice/IoU、macro Dice、耗时；检测非有限输出/梯度并失败退出。
- `best.pth` 按固定阈值 0.5 的验证 pooled Dice 保存；`latest.pth` 含优化器、调度器、RNG、历史记录。检查点通过临时文件再替换，避免覆盖到一半。
- 不在训练结束自动评估测试集。输出目录必须新建，恢复时显式 `--resume`。

## 5. 已完成候选：R3 保留预训练解码器的多尺度上下文恢复

### R2 已有结果与决策

2026-09-08 读取服务器结果：seed42 完成 300 轮，最佳 Dice=89.8743%，相对同种子 B0 +0.9890 个百分点；seed43 完成 300 轮，最佳 Dice=88.5868%，相对 B0 −1.3780 个百分点。两组均值下降约 0.1945 个百分点。seed44 当时约 192/300 轮，暂时最佳 89.7062%；它不是完整结果，不纳入完成实验的均值。

R2 seed43 的 boundary F1 从 B0 的 46.1883% 降到 38.0291%。两组均未出现非有限数值，后期训练损失降低而验证效果回落，有过拟合迹象，但不能据此断言某个分支是原因。代码和配置核对一致。停止扩展 R2 参数搜索，现有 `--decoder multiscale` 保留以读取历史检查点。

用户 GPU 预算紧张，下一轮直接评估一个整体结构候选，不逐个跑小模块消融。R3 的假设是：保留原版预训练编码器与解码器的已有能力，以联合上下文改善各层解码，并学习高分辨率残差修正。R2 放弃了解码器预训练，但现有实验尚不能证明这是退化原因；R3 也不保证涨点或新颖性。

### R3 结构与初始化

实现 `models/vmunet/context_adapter.py`，使用 `--decoder context`：

```text
原图 → 原 Mamba 编码器 → 四尺度特征分别投影 32 通道
                             ↓ 对齐到 1/4 分辨率并联合卷积融合为 64 通道
                             ├→ 三个尺度的上下文残差 → 原 skip 相加 → 原 Mamba 解码器
                             └→ 与解码器末端 1/4 特征拼接
                                  → 卷积 → PixelShuffle ×2 → PixelShuffle ×2 → 残差 logits
原解码器 → 原 FinalPatchExpand → 原分类头 logits ──────────────────────相加 → sigmoid
```

- 保留原 `layers_up`、`final_up`、`final_conv` 及原有预训练映射；不从 B0 已选最佳权重或 R2 权重热启动，仍使用同一个公开预训练文件。
- 四尺度来源与 R2 相同：patch embedding、两个中间下采样特征以及经过最后编码块的 bottleneck。上下文补充到原来的三处 skip，原相加路径保留。
- 高分辨率分支从编码/解码特征渐进恢复，不使用 R2 的原图旁路，也不使用竞争门控。
- 三个 skip 残差投影和最终残差分类层零初始化。新增模块安装在原预训练加载之后，保持原模块权重和 CPU RNG；初始预测与原版相同。首步只有残差输出层学习，输出层更新后梯度进入内部分支，这是预期行为。
- R3 总参数 27,967,610，其中新增分支 540,049；保留原网络并改变跨尺度信息流和恢复路径，参数增幅约 2%。
- 原模块与新分支一起训练，损失仍为 BCE+Dice，分辨率、batch、优化器及学习率计划与 B0 一致。R3 有额外计算，不能用 R2 的每轮耗时估计它。
- `decoder=context` 写入配置与检查点，分析工具自动恢复结构；不能把不同模型变体的 `latest.pth` 混用。R1 与 R2 继续可用，但不与 R3 组合。

### 设计依据与证据边界

1. 本项目直接证据：旧单层门控实验相对历史原版只高约 0.0453 个百分点，且仅一个种子；R2 两个完成种子的平均效果未提升。因此没有依据继续只堆门控，也没有依据认定整体替换解码器已经成功。
2. 结构依据：[UNet 3+](https://arxiv.org/abs/2004.08790) 通过全尺度连接组合低层细节与高层语义；[UNet++](https://arxiv.org/abs/1807.10165) 通过重设计 skip 路径处理编码与解码特征间的语义差异。这些研究支持“改善跨尺度信息融合”的方向，不证明本项目 R3 的共享上下文结构或具体通道数最优。R3 不是这两篇方法的完整复现。
3. 保留预训练解码器的判断：B0 已有可复现表现，R2 同时改变解码结构和初始化来源，退化原因尚未隔离。保留已有路径是在已工作的模型上增加可学习修正，减少破坏已有能力的风险；不能把“缺少解码器预训练导致 R2 失败”当成已证实结论。
4. 高分辨率恢复的判断：原模型从 1/4 特征通过一次四倍 PatchExpand 和分类生成输出。R3 增加两级可学习恢复，并结合四尺度上下文；这是针对输出恢复路径的结构假设。现有边界指标只说明边界效果需要关注，未证明输出上采样是错误根因，更未证明 PixelShuffle 必然更好。
5. 零初始化的作用限于保持初始预测等价；它不是涨点证据，也不保证训练后不退化。32/64 通道和两级恢复属于实现选择，尚无本项目的最优性证据。

结论：R3 是跨三个解码阶段和输出恢复路径的结构性扩展，非调学习率或仅替换一个门控；但它仍保留原骨干，不应描述为已验证的大幅效果提升。当前证据足以把它列为有理由验证的候选，不足以认定为论文最终方法。真正的研究主张是“全尺度上下文能否改善保留预训练解码器的分割恢复”，效果及各部分贡献需后续实验验证。

## 5.1 当前方案 R4 基线初始化与正确高置信像素约束

R3 seed43 完成 300 轮，最佳 Dice 89.5243%，低于同种子 B0 的 89.9648%。[推理诊断](R3诊断_2026-09-08.md)显示部分图像改善、部分原本正确图像严重退化；新增分支确实参与预测。R4 不再增加结构，改为从已有 B0 能力出发，在训练中约束退化。这是待验证假设，约束训练像素不能保证验证集或未见图像不退化。

### 实现

- `--init-checkpoint` 严格加载受控 B0（必须是 original，无 R1、无边界加权），然后才安装 R3 的零初始化 context 分支。方法组初始评估预测与 B0 一致；原模型继续训练组也从同一个文件开始。
- 配对检查 seed、manifest SHA256、输入尺寸和预处理；初始化文件 SHA256 写入新配置，恢复时必须一致。`--pretrained` 在此模式不加载；旧 R3 权重不用于初始化。
- `--teacher-weight 1` 开启冻结 B0 教师：eval 模式、无梯度、无优化器更新；教师随学生对同一增强后的训练图推理。教师不需要标注预测；用训练 GT 检查教师正确性后选像素。
- 像素选择：教师分类正确，且其二分类置信度 >= `--teacher-confidence 0.9`。在这些位置计算 teacher→student Bernoulli KL，前景/背景各求均值后对存在的类别等权平均，避免背景数量主导。没有合格像素时返回可反传的零；教师错误或不确定的位置不受该项约束。
- 总损失 = 原 BCE+Dice + teacher_weight × KL。`teacher_kl` 和 `teacher_coverage` 写入逐轮 CSV；`train_loss` 包含约束，不能直接与原 BCE+Dice 数值作等价比较。验证仍只用原分割损失和阈值 0.5。
- 教师只参与训练，不访问验证标签、不参与推理。评估 R4 仅需学生 best.pth；恢复训练需要原 B0 文件，以其指纹保证教师一致。
- 新实验重新初始化 AdamW 和 cosine，属于新继续训练阶段而非 B0 优化器断点恢复。方法与对照使用相同设置。先评估并保存第 0 轮 best.pth；若后续没有刷新初始值，明确报告“没有增益”，不能将保留基线称为成功。

## 6. 正式论文协议与继续/停止标准

首轮单 seed 只筛选。正向后跑 seed=42/43/44，报告均值、标准差、每个 seed 的配对差值；方法有一致收益后再补第二数据集及相关强基线。不能保证 1–2 点提升，更不保证投稿结果。

正式协议可在原 train 内冻结验证集：

```bash
python prepare_full_split.py --data-path data/isic2018 \
  --val-fraction 0.2 --seed 42 --output splits/full_isic18_internal.json
```

此时 train 内所有剩余图像都使用标注，仍是全监督；但训练样本数减少，必须重跑 baseline。旧 val 已用于开发，不应称为严格未见测试；需要新的未触碰测试集/外部数据，且按患者或病灶分组，明确历史使用情况。独立数据可以整理为 `test/images`、`test/masks`，使用 `analyze_full.py --split test`，不传 manifest。

继续：相对新 B0 的改进在多 seed 可重复，诊断目标指标同时改善，第二数据集支持；再细化方法并做文献查重。停止或改方向：收益与随机波动相当、只在单 seed 出现、边界指标改善但整体显著恶化、训练设置变化解释了收益。先分析失败，不连续堆模块。
