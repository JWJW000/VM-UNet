## 1. 研究问题（写进论文 Introduction）

**RQ1（主）** 在只有 5%/10%/20% 像素级标注时，扫描扰动一致性是否优于「同一骨干 + 普通 Mean-Teacher」？

**RQ2（机制）** 方向一致性（互补 2 向互相对齐）是否提供独立于扫描扰动的增益？

**RQ3（泛化）** ISIC18 上训练的模型，在 ISIC17 上是否比全监督少标注基线掉点更少？

非目标（审稿人会问，提前写进 Limitations）：

- 不宣称 3D 全容积 SOTA（本仓库是 2D）
- 不宣称比 nnU-Net / MSVM-UNet 在全监督 Synapse 上全面更强
- 不把参数量再砍一个数量级当作贡献

## 2. 方法与代码对应

训练一次无标注 batch 时发生的事：

```
教师  EMA, eval, scan_mask = [1,1,1,1]     →  p_t
学生A train, 随机 2 向                       →  p_a
学生B train, 互补的另外 2 向                 →  p_b

L_sup  = BCE+Dice(学生(有标注), y)          # 学生有标注走全 4 向
L_cons = 置信 MSE(p_a, p_t.detach())        # 扫描扰动一致性
L_dir  = MSE(p_a, p_b) 对称                 # 方向一致性
L      = L_sup + λ_cons(t) L_cons + λ_dir(t) L_dir
然后 EMA 更新教师
```

| 概念 | 文件 |
|------|------|
| 4 向加权 / 丢方向 | `models/vmunet/scan_utils.py`，`SS2D.forward(..., scan_mask)` |
| SSL 循环 | `scan_ssl/engine.py` |
| 冻结划分 | `scan_ssl/splits.py` → `splits/*.json` |
| 入口 | `train_ssl.py` |
| 跨域 | `eval_cross_domain.py` |
| 超参 | `configs/config_ssl.py` |

默认超参（先不要改，跑通主表再调）：

- `labeled_ratio=0.1`，`labeled_batch_size=8`，`unlabeled_batch_size=24`
- `ema_decay=0.99`，`cons_weight=1.0`，`dir_weight=0.5`
- `rampup_epochs=50`，`conf_lo=0.2`，`conf_hi=0.8`，`scan_keep=2`
- `ssl_seed=42`

全监督 `python train.py` 仍可用；`scan_mask=None` 时与原 4 向求和一致。

## 3. 必须先守住的实验协议

否则数字无法和别人比，也无法自己复现。

1. **划分文件是论文附件**。一旦生成 `splits/isic18_r0p1_s42.json`，提交进 git，禁止重跑覆盖。换 seed 另存新文件。
2. **本仓库 ISIC 是 7:3 自划**，与 ISIC 官方挑战划分不同。论文 Methods 必须写明，表格标题写 “ISIC18 (repo 7:3 split)”。
3. **跨域归一化只用源域统计**（`eval_cross_domain.py` 已这样做）。禁止用 ISIC17 的 mean/std 去测「从 18 迁到 17」。
4. **无标注图像的 mask 不得进入 `L_sup`**。loader 仍会读到 mask，但 `scan_ssl/engine.py` 只把 unlabeled 用于一致性。
5. **每个设定至少 3 个 seed**（42/43/44）。主表报 mean±std。硕士答辩可以先 seed=42，投稿前补齐。
6. **选模型用验证 DSC，不是训练 loss**。当前 `val_one_epoch` 多数 epoch 只打 loss、每 `val_interval=30` 才打 DSC。正式实验把 `val_interval` 改为 `1`，按验证 DSC 存 `best.pth`。

### P0 — 没有这些就没有论文

在 **ISIC18** 上，同一冻结划分：

| ID | 设定 | 命令 / 做法 | 用来回答 |
|----|------|-------------|----------|

## 6. 怎样算「这条线成立」（Go / No-Go）

在 ISIC18、10% 标注、3 seed 平均：

| 结果 | 判断 |
|------|------|
| M1 比 B1 高 **≥1.5 DSC**，且 A1、A2 都低于 M1 | **Go**，按会议稿写 |
| M1 比 B1 高 0.5–1.5 DSC，消融方向对 | **弱 Go**：补 Synapse 或跨域掉点故事，投 workshop / CBM / BSPC |
| M1 ≈ B1，或 A2（无扫描扰动）≈ M1 | **No-Go 当前机制**。不要加模块硬涨点。改为：扫描顺序作为数据增强、或置信度按方向分歧加权。先做诊断再改方法 |
| 跨域 X1 上 M1 掉点少于 B1 | 即使源域增益一般，也可把 claim 改成稳健性 |

诊断（No-Go 时先做，不要空想新模块）：

- 画出 4 个单方向预测的像素方差图：病灶边缘是否更高
- 教师–学生一致性是否只在背景上成立
- 5% 标注是否已经塌缩（需要更强伪标签过滤）

## 10. 风险与依赖

| 风险 | 处理 |
|------|------|
| `mamba_ssm==1.0.1` + CUDA 装不上 | 先在已能跑 `train.py` 的机器上做 SSL，不要为 SSL 换环境 |

| 方向一致性多一次前向，显存不够 | 先减小 `unlabeled_batch_size`；再关掉 `--no_dir_consistency` 做 A1，不要一上来改网络 |

## 11. 本周具体命令

在已经能跑原版 `train.py` 的机器上：

```bash
# 1) 单测（有 torch 的环境）
python -m pytest tests/test_scan_utils.py tests/test_ssl_split.py

# 2) 确认全监督还能跑（B0，可先短 epochs 试通路）
python train.py

# 3) 主方法 10%（M1）
python train_ssl.py --labeled_ratio 0.1 --datasets isic18 --gpu 0

# 4) 消融
python train_ssl.py --labeled_ratio 0.1 --datasets isic18 --no_dir_consistency
python train_ssl.py --labeled_ratio 0.1 --datasets isic18 --no_scan_dropout

# 5) 跨域（ckpt 换成实际 best 路径）
python eval_cross_domain.py \
  --ckpt results/<run>/checkpoints/best-epoch*-loss*.pth \
  --source isic18 --target isic17
```

本周结束时至少应有：B0 的验证 DSC、M1 是否能完整训起来、一张 split json 已提交。
